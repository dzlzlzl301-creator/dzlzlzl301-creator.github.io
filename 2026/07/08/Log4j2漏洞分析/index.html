JNDI 全称是 Java Naming and Directory Interface，即 Java 命名和目录接口。

2. LDAP 是什么

LDAP 全称是 Lightweight Directory Access Protocol，即轻量级目录访问协议。

在正常场景中，LDAP 常用于查询用户、组织、权限等目录信息。

七、漏洞根本原因

Log4j2 CVE-2021-44228 的根本原因可以概括为：

日志组件对不可信输入进行了表达式解析，并且支持通过 JNDI 访问远程资源，导致攻击者可以控制远程查找地址，进而加载恶意代码。

问题点包括：

  1. 用户输入可控；
  2. 用户输入进入日志；
  3. Log4j2 对日志内容进行 Lookup 解析；
  4. JNDI Lookup 支持 LDAP/RMI 等远程协议；
  5. Java 远程类加载或恶意对象处理导致代码执行。

CVE-2022-22947_Spring_Cloud_Gateway

1. 漏洞概述

CVE-2022-22947 是 Spring Cloud Gateway
中存在的远程代码执行漏洞。漏洞产生于 Gateway Actuator
管理接口在特定配置下暴露后，攻击者可以未授权调用动态路由管理功能，添加恶意
RouteDefinition，并利用 Gateway Filter 参数进入 SpEL（Spring Expression
Language）表达式解析流程，最终导致服务器执行任意代码。

该漏洞编号为 CVE-2022-22947，属于高危远程代码执行漏洞。
